# 糖糖和许愿的表情包

这是糖糖和许愿共同整理的表情包仓库。仓库包含 100 张图片，并为每张图片记录名称、类别、适用场景和检索标签。

## 仓库内容

- `stickers/`：统一压缩为 PNG 的表情图片
- `catalog.json`：机器可读的完整表情目录
- `index.html`：可视化浏览页，可部署为 GitHub Pages
- `SKILL.md`：供支持技能说明的模型读取

## 目录字段

`catalog.json` 中每张表情包含以下字段：

- `id`：稳定且唯一的表情编号
- `label`：表情名称
- `category`：主要情绪或用途分类
- `meaning`：适合使用的聊天场景
- `tags`：自然语言检索关键词
- `image`：仓库内图片路径
- `private_context_only`：是否只适合明确的成人私密或调情语境

## 使用原则

1. 根据当前聊天的情绪和动作选择最贴合的一张。
2. 一次通常只发送一张，避免连续刷屏。
3. 图片应放在回复正文中，不作为独立的大图附件发送。
4. `private_context_only` 为 `true` 的图片只在用户明确开启成人私密或调情语境时使用。
5. 普通聊天、工作和公开社交场景不得自动使用私密表情。

## GitHub Pages

在仓库设置中打开 Pages，并选择从 `main` 分支根目录部署，即可通过网页浏览全部表情。图片本身也可以通过 GitHub Pages 或 `raw.githubusercontent.com` 的固定地址引用。

## 添加新表情

1. 将图片压缩为 PNG 并放入 `stickers/`。
2. 使用新的唯一 ID 命名，已有 ID 不要改动。
3. 在 `catalog.json` 追加名称、适用场景和标签。
4. 打开预览页检查图片与说明是否对应。
